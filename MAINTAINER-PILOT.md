# Maintainer pilot

Owner: SpannDaMan

No private maintainer pilot has been completed. The scoped publication override in [PUBLICATION-GATE.md](PUBLICATION-GATE.md) preserves that fact and does not convert the targets below into current outcomes.

If run after publication, the pilot should record receipt creation success, unchanged verification success, deliberate-tamper detection, command overhead, unsupported filesystem cases, support effort, and confusing claim interpretations. Any receipt, canonicalization, HMAC, Git normalization, path-selection, exit-code, or privacy change requires tests, a changelog entry, and fresh revision binding.

Targets remain prospective: at least 95% loadable receipts for started bounded commands, identified selected-file changes, stable unchanged verification after documented nondeterministic outputs are excluded, sub-two-second median overhead for selections under 10,000 files and 100 MB, and correct interpretation of non-claims by at least four of five maintainers.

Pause for receipt overwrite, selected-symlink escape, a changed selected file reported unchanged, exposed file contents, HMAC downgrade acceptance, a committed secret, repeated Git-state instability, or an open P0-P2 finding.
